The language app that measures what you actually know.

A calm, evidence-based counter-proposal to gamified learning. No streaks, no XP — just comprehensible input, honest recall, and memory scheduled by the real forgetting curve.

The idea

“Duolingo’s problem isn’t its method. It’s what it measures.”

Research is clear that time-in-app doesn’t predict acquisition — accuracy does. So the whole identity is built to feel trustworthy and quiet, the opposite of a slot machine: paper-warm grounds, one restrained amber signal, data set in a precise mono. The name Orin is coined, not descriptive — short, open-vowelled, and calm by design. It doesn’t announce what the app does; the product does that. Chosen to be genuinely ownable.

Honest

Every metric reflects real knowledge — recall accuracy, mastered items, vocabulary coverage. Never a streak.

Grounded

Comprehensible input at 95–98% coverage, retrieval practice, FSRS scheduling. Each claim traces to a citation.

Calm

No confetti, no pressure loops. The interface gets out of the way so the learning is the reward.

Identity system

A mark, a palette, and a voice — kept deliberately spare.

The logo is the forgetting curve itself, boxed: memory that decays and is rescued by review. Boldness is spent in exactly one place — the amber signal — and everything around it stays monochrome.

The product

One learning loop, five moments.

Read at your level → recall from memory → say it aloud → let the schedule do the spacing. The chrome is English (the global product); a learner’s own language appears only as translation glosses.

Design principles

Rules the interface has to keep.

01

Measure knowledge, not habit

Accuracy, mastery, and coverage are surfaced. Streaks and XP are structurally absent — they measure habit, not learning.

02

One signal, quietly

Amber marks exactly one thing at a time — an unknown word, an answer, a due item. Everything else stays monochrome.

03

Honest about the machine

Automated speech feedback is framed as approximate guidance. The app never fakes a precision it doesn’t have.

04

Calm over compulsion

No dark patterns, no manufactured urgency. Sessions end cleanly. The learning is the reward.
